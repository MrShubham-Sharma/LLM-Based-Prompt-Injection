Privacy Policy

Effective date: October 2026  ·  SecureLLM

1. Overview

SecureLLM is a locally-hosted prompt injection defense proxy. This policy describes what data is processed when you use SecureLLM and how that data is handled.

2. Data We Process

When you send a prompt through SecureLLM, the following data is processed:

  • The text of your prompt, for the purpose of running the three-layer defense pipeline.
  • Any RAG or tool context you attach, used solely for the same defense screening.
  • System instructions you configure, stored locally in your browser session only.

3. Data We Do Not Collect

SecureLLM does not collect, store, or transmit your prompts to any SecureLLM server. All defense processing runs locally on your machine. No analytics, tracking pixels, or third-party data collection scripts are included.

4. Third-Party AI Providers

When you send an approved prompt to an AI provider (Gemini, OpenAI, Anthropic), that request is sent directly from your machine to that provider using your own API key. Each provider's own privacy policy governs how they handle that data. SecureLLM does not proxy, log, or intercept that exchange.

5. API Keys

API keys you enter are stored only in your browser session memory and are never transmitted to any SecureLLM server. They are sent directly to the respective AI provider API endpoint for authentication.

6. Browser Extension

The SecureLLM browser extension sends prompt text from supported AI chat interfaces to your locally-running SecureLLM instance (127.0.0.1) for screening. No prompt data leaves your local network through the extension.

7. Changes to This Policy

We may update this policy. Material changes will be reflected with a new effective date. Continued use of SecureLLM after changes constitutes acceptance of the updated policy.

8. Contact

Questions about this policy can be directed to the SecureLLM project repository. As an open-source tool, the full source code is available for inspection.
